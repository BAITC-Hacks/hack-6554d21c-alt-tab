# Saqta — план реализации v2

Цель: согласованный одностраничный симулятор с трассой, текстовым REST и голосом LiveKit. Спецификация: DESIGN.md; запуск, контракт и ручная приёмка: README.md.

## Ограничения

- Только frontend/**, включая зависимости и lockfile.
- Сервер владеет решениями, историей и подтверждением действий.
- Явный Mock, без автоматического перехода при ошибке Live.
- Ключи провайдеров остаются на сервере.
- RU/KK/mixed, русские подписи, измеренные метрики либо null.
- LiveKit заменяет файловый аудиотранспорт; текстовый резерв без озвучивания.

## Реализовано

- [x] React/TypeScript/Vite, адаптивный разговор и полная трасса.
- [x] Zod, REST health/session/text/history/livekit, ошибки, отмена и повтор с тем же request_id.
- [x] Явные примеры Mock, preview/execute, подтверждение и handoff.
- [x] Дедупликация по turn_id, сортировка и защита от поздних ответов старой сессии.
- [x] Разрешение микрофона до выдачи комнаты, динамический LiveKit, публикация и remote audio.
- [x] Проверка агента/topics/session, autoplay, переподключение и освобождение треков.
- [x] Восстановление истории, в том числе после ручного stop; независимый от говорящих polling.
- [x] Валидный trace компенсирует потерянный ready; configured не выдаётся за проверенный голос.
- [x] Unit/component и браузерные регрессии; предыдущая независимая проверка трёх исправлений.
- [x] Документация обновлена под v2.
